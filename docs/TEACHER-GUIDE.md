# 서평 고쳐쓰기 사용 안내

## 수업 흐름
1. 교사는 `/teacher`에서 ChatGPT 계정으로 로그인하고 교실을 한 번 만듭니다.
2. 학생은 출석번호를 선택하고 종이에 쓴 초고를 1~4장 촬영합니다. 미리보기에서 글씨 방향을 확인하고, 필요하면 사진별 ‘사진 돌리기’를 눌러 90도씩 돌린 뒤 피드백을 받습니다.
3. 왼쪽 사진의 번호와 오른쪽 피드백 카드를 연결해 살펴봅니다.
4. 첫 화면의 빠진 요소 목록과 확실히 인식한 표기 오류를 모두 확인해 종이에 고칩니다. 자세한 내용 쓰기 안내는 우선순위가 높은 한 가지를 제공합니다.
5. 고친 곳을 표시하고 선생님께 확인을 요청합니다. 두 번째 평가는 AI가 하지 않습니다.
6. 교사는 같은 사진·피드백, 요청 상태, 수정 표시를 보고 실제 종이를 함께 지도합니다.

## AI와 교사의 역할
AI는 다섯 요소와 까닭의 존재, 확실한 맞춤법·띄어쓰기·문장부호를 확인합니다. 제목의 매력, 핵심 사건의 선정, 책 내용과의 일치, 근거의 타당성과 설득력은 교사가 판단합니다. 제목·작가·출판사 등 소개 예시를 모두 필수로 강요하지 않습니다. 추천은 추천 의사를 썼을 때만 대상·까닭을 확인합니다.

사진 인식 결과는 틀릴 수 있습니다. confidence는 모델의 신뢰도 지표이며 정확성을 보장하지 않습니다. 불확실한 줄은 표기 지적에서 제외하고, 낮은 신뢰도의 글이 많으면 촬영 상태부터 확인합니다. 사진이 선명한데 글자 모양을 읽기 어렵다고 분류될 때만 또박또박 써달라고 안내합니다. 학생은 언제든 오인식 또는 교사 도움을 요청할 수 있습니다.

출석번호는 간편 접속용 표식입니다. 본인 인증 수단은 아니며 같은 번호를 다른 사람이 선택할 수 있습니다. 단, 번호를 안다고 다른 기기의 기존 글을 조회할 수는 없습니다. 제출물은 HTTP-only 기기 세션과 연결되고, 교사만 전체 글에 접근합니다. 공동 기기는 학생이 바뀔 때 반드시 '사용 마치기'를 누릅니다. 학생 세션은 12시간 유지됩니다.

## 시작 전 필요한 연결
Google Cloud Vision API(문서 인식)와 Vertex AI API(Gemini 피드백)를 사용합니다. Gemini 웹 구독 또는 AI Studio 무료 키와는 별개입니다. 크레딧 적용·만료·서비스별 자격은 Google Cloud Billing에서 직접 확인해야 합니다. 크레딧이 소진되면 결제 설정에 따라 과금될 수 있습니다.

현재 하루 제한은 출석번호당 10회, 교실 전체 120회입니다. 횟수는 한국 시간 오전 9시에 초기화됩니다. 실패한 외부 호출도 요청 횟수에 포함됩니다. 이 제한은 앱 요청 제한이며 Cloud 결제의 완전한 지출 상한은 아닙니다. 교사 화면의 사진 접수 스위치로 새 접수를 닫을 수 있습니다.

## 배포와 접근
최초 배포는 소유자 전용입니다. 이 상태에서 교실을 먼저 만들고 실제 사진을 시험한 후 학생 접속이 가능한 공개 접근으로 전환해야 합니다. 공개 전에 미등록 상태를 방치하지 마세요. 교사 권한은 교실을 처음 만든 계정에 고정됩니다. 학생들에게 ChatGPT 로그인을 요구하지 않으려면 사이트 바깥쪽 접근 정책이 익명 방문을 허용해야 합니다.

사진은 서버 저장소에, 인식 글·피드백·교사 메모는 DB에 보관됩니다. 수업 후 교사가 제출물을 삭제하면 사진과 해당 기록을 함께 지웁니다. 자동 보관기한은 현재 없으므로 필요가 끝난 기록은 삭제해주세요. 서비스 계정 비밀키와 사진은 GitHub에 올리지 않습니다.
